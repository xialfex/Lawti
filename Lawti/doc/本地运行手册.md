## 3. 运行方式

本手册提供两种运行方式，任选其一。

### 方式一：VS Code + Live Server

1. 安装 VS Code。
2. 在扩展市场中搜索并安装 Live Server。
3. 使用 VS Code 打开 lawti 文件夹。
4. 右键 index.html，选择 Open with Live Server。
5. 浏览器自动打开 http://127.0.0.1:5500。

### 方式二：Python 静态文件服务

1. 确认 Python 已安装：
python --version

text

2. 进入 lawti 文件夹：
cd 路径/lawti

text

3. 启动静态服务：
python -m http.server 8000

text

4. 浏览器访问：
http://127.0.0.1:8000

text

说明：此处的 Python 仅作为静态文件服务器使用，不涉及 Flask 或任何后端框架。

## 4. 线上访问

项目已部署至 Vercel，可通过以下地址访问：

- Vercel 默认域名：https://lawti-shupl.vercel.app
- 自定义域名：https://www.lawti-shupl.top

线上版本与本地版本代码一致，用户可直接访问，无需本地运行。

## 5. 直接双击 HTML 的限制

浏览器出于同源策略，禁止本地 HTML 文件通过 fetch 读取本地 JSON 文件。因此必须通过上述两种方式之一启动本地服务，不能直接双击 index.html。

## 7. 移动端访问（本地）

同一局域网内，手机可访问电脑运行的本地服务。

1. 查询电脑 IP 地址：
- Windows：命令行执行 ipconfig，记录 IPv4 地址
- macOS：命令行执行 ifconfig，记录 en0 下的 inet 地址

2. 手机浏览器访问：
http://电脑IP:8000

text

示例：http://192.168.1.5:8000

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面提示“题库加载失败” | 未通过本地服务打开 | 使用 Live Server 或 http.server |
| 选项点击无反应 | JS 报错 | 打开浏览器控制台（F12）查看错误 |
| 结果页提示“没有找到测试记录” | 未完成完整答题流程 | 从 index.html 重新开始 |
| 海报下载失败 | html2canvas CDN 未加载 | 检查网络连接 |
| 手机无法访问 | 设备不在同一局域网 | 确认 WiFi 一致，检查防火墙 |

## 9. 云端数据说明

项目已接入 Supabase 云端数据库。用户完成测试后，数据会同时写入：

1. 浏览器本地 localStorage（用于 data.html 展示和导出CSV）
2. Supabase 云端 lawti_records 表（用于开发者查看所有用户记录）

查看云端数据方式：

1. 登录 https://supabase.com
2. 进入项目 → Table Editor → lawti_records
3. 可查看所有记录，或点击右上角 Export 导出CSV

若云端上传失败，不影响用户体验，数据仍会保存到本地。

## 10. 域名说明

项目已购买域名 `lawti-shupl.top`（腾讯云），并通过 DNS 解析指向 Vercel。

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| A | @ | 76.76.21.21 |
| CNAME | www | cname-china.vercel-dns.com |

CNAME 使用 `cname-china.vercel-dns.com` 而非 Vercel 默认地址，目的是优化国内访问稳定性。
